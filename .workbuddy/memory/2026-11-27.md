## 修复 favicon 不生效
- 根因：项目用 Cloudflare Worker + 无 assets 绑定，public/ 不自动托管；`/favicon.ico` 无路由 → 落到 notFound() 返回 404 HTML。另外 href 用的是相对路径，在 `/s/token`、`/admin/`、`/market/` 下会被解析成 `/s/favicon.ico` 等错误地址。
- 改动：
  - `wrangler.jsonc` 增加 `{ "type": "Data", "globs": ["**/*.ico"] }` 规则；`src/assets.d.ts` 增加 `*.ico` 声明。
  - `src/index.ts` 顶部 import `../public/favicon.ico`，在 route() 最前面（不查 DB）返回 `/favicon.ico`，content-type `image/x-icon`，缓存 7 天。
  - `public/{admin,share,market}.html` 与 `src/pages.ts` 的 errorPage 均改为 `href="/favicon.ico" type="image/x-icon"`。
- 验证：tsc 通过；wrangler dev 下 `/favicon.ico` 返回 200 / 60435 字节 / image/x-icon。
- 备注：仓库里同时存在 wrangler.jsonc 和 wrangler.toml，wrangler 实际生效的是 jsonc（toml 的 database_id 仍是 local-db）。
